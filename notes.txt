installation steps
******************
keep required libraries into requirements.txt file
like the below
numpy
pandas
openpyxl
seaborn
jupyter
matplotlib

run the below commands in the command prompt
pip install -r .\requirements.txt

we can install the below libraries in one line
pip install numpy pandas seaborn matplotlib jupyter

lunch the jupyter
jupyter-notebook

for latest python.exe we need to install the below
python.exe -m pip install --upgrade pip

uvicorn - this is the server used to run the api calls
fastapi - this is the api used for api call operations

to run the api use the below command
uvicorn apiCall:app --reload

uvicorn - is the server
apiCall - is the fileName
app - is the instance created
--reload - server restart
