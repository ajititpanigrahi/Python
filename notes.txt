uvicorn - this is the server used to run the api calls
fastapi - this is the api used for api call operations

to run the api use the below command
uvicorn apiCall:app --reload

uvicorn - is the server (light weight http server)
apiCall - is the fileName
app - is the instance created
--reload - server restart

once we execute uvicorn apiCall:app --reload we will get below url
Uvicorn running on http://127.0.0.1:8000
in browser http://127.0.0.1:8000/docs -- it will display the swaggerui
FastAPI is supporting swaggerUI by default
