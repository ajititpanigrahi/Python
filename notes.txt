installation steps
******************
keep required libraries into requirements.txt file
like the below
numpy
pandas
openpyxl
seaborn
jupyter
matplotlib

run the below commands in the command prompt
pip install -r .\requirements.txt
pip install seaborn jupyter

lunch the jupyter
jupyter-notebook

for latest python.exe we need to install the below
python.exe -m pip install --upgrade pip
